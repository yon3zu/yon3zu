## About

Developer with hands-on experience in automation, web scraping, browser automation, and Telegram bot development, with a focus on building practical tools for real-world use cases in the Indonesian tech ecosystem. Currently expanding into the MERN stack and exploring opportunities in digital product development and dev collaborations.

With a strong focus on cybersecurity, I founded and run several ventures in the security and infrastructure space:

- **[XploitSec](https://xploitsec.com/)** — security research team and tooling
- **[LinuXploit](https://linuxploit.com/)** — Linux security & infrastructure
- **[xLabsCloud](https://client.xlabscloud.com/)** — RDP hosting provider built for penetration testing workflows
- **[xReverseLabs](https://xreverselabs.org/)** — Open Source Intelligence & security research organization
